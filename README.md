# NBQ

The NBQ app: log what you eat and see how much of each nutrient your day covers, scored by the
Net Benefit Quotient (absorbable nutrition per calorie). Open it at https://jet427.github.io/nbq/

This repository holds only the built app, published from a private source repository
(build bdfb743). Everything you log stays in your browser; scanning a barcode sends only the
barcode to Open Food Facts.

Food composition data: USDA FoodData Central (public domain). Packaged-food data: Open Food Facts
(Open Database License).
